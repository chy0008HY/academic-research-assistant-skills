# Research Data Quality

1. Define unit of observation, primary key, source, collection window, and expected rows.
2. Create a dictionary with type, allowed values, units, missing codes, derivation, and sensitivity.
3. Test uniqueness, completeness, validity, consistency, temporal order, referential integrity, and plausible ranges.
4. Reconcile denominators and totals across raw data, tables, figures, and manuscript claims.
5. Log corrections without overwriting raw evidence.
6. Classify issues as blocking, material, minor, or informational.

Analysis proceeds only when blocking issues are resolved or explicitly accepted with documented impact. Never silently impute, drop, relabel, or deduplicate observations.
