# Reproducibility and Open Science

1. Freeze raw inputs and record hashes, provenance, licenses, consent limits, and access controls.
2. Separate confirmatory, preregistered, exploratory, and post-hoc decisions.
3. Record software, versions, parameters, random seeds, environment, and execution order.
4. Link each table, figure, and reported number to its generating input and procedure.
5. Build a manifest for data, code, materials, documentation, checksums, and identifiers.
6. Draft accurate availability statements; do not promise public access for restricted data.
7. Run a clean-environment reproduction attempt and record deviations.

Return a manifest, decision log, sharing constraints, blockers, and verification actions.
