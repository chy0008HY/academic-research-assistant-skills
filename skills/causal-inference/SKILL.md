# Causal Inference

1. State exposure, outcome, population, time horizon, and target estimand.
2. Separate prediction, association, and causal questions before analysis.
3. Record the assumed causal structure: confounders, mediators, colliders, and modifiers.
4. Match identification strategy to explicit assumptions; regression alone does not identify causality.
5. Check positivity, consistency, interference, timing, measurement error, attrition, and missingness.
6. Plan falsification, sensitivity, alternative specifications, and subgroup analyses.
7. Calibrate manuscript language to the strongest defensible conclusion.

Return the estimand, assumptions, identification strategy, threat table, robustness plan, and wording boundary. Mark conclusions that depend on untested assumptions.
