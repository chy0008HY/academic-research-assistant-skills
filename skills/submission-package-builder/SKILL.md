# Submission Package Builder

1. Snapshot official requirements with URL, retrieval date, article type, and manuscript version.
2. Build a manifest listing required files, owner, version, anonymization state, status, and dependency.
3. Cross-check title, authors, funding, conflicts, ethics identifiers, statements, counts, figures, tables, supplements, and references.
4. Keep identifiable and blinded files separate; scan metadata and acknowledgements for disclosure.
5. Map reviewer comments to response, manuscript location, change evidence, and unresolved issue.
6. Produce files for human inspection. Never submit automatically or certify compliance without author confirmation.

Return package readiness, missing or conflicting items, blocking issues, and a final approval checklist.
